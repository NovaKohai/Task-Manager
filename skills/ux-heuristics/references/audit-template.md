## Heuristic Checklist

### 1. Visibility of System Status
- [ ] Loading indicators present for async operations
- [ ] Confirmations shown for completed actions
- [ ] Progress indicators for multi-step processes
- [ ] System status clearly communicated

### 2. Match Between System and Real World
- [ ] Uses plain language, not jargon
- [ ] Follows real-world conventions
- [ ] Natural information ordering

### 3. User Control and Freedom
- [ ] Undo available for non-destructive actions
- [ ] Cancel/back options on every screen
- [ ] Emergency exits clearly labeled

### 4. Consistency and Standards
- [ ] Internal consistency throughout
- [ ] Platform conventions followed
- [ ] Same terms used everywhere

### 5. Error Prevention
- [ ] Constrained inputs used where appropriate
- [ ] Confirmation for destructive actions
- [ ] Sensible defaults provided

### 6. Recognition Rather Than Recall
- [ ] Options visible, not buried in menus
- [ ] Recent history/search available
- [ ] Instructions visible when needed

### 7. Flexibility and Efficiency of Use
- [ ] Shortcuts for power users
- [ ] Bulk actions available
- [ ] Progressive disclosure used

### 8. Aesthetic and Minimalist Design
- [ ] No unnecessary elements
- [ ] Clear visual hierarchy
- [ ] One primary CTA per page

### 9. Help Users Recognize, Diagnose, and Recover from Errors
- [ ] Error messages in plain language
- [ ] Specific guidance on how to fix
- [ ] User input preserved

### 10. Help and Documentation
- [ ] Help is searchable
- [ ] Task-focused content
- [ ] Contextual help available
